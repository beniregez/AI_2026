\noindent We provide a heuristic $h$ for $\mathcal{S}$ such that:
\begin{itemize}
    \item IDA$^*$ performs at least 4 iterations
    \item exactly one new path is reachable within the new f limit in each iteration
\end{itemize}
$h: \{
    s_I \mapsto 1,
    s_1 \mapsto 0,
    s_2 \mapsto 1,
    s_3 \mapsto 1,
    s_4 \mapsto 0,
    s_g \mapsto 0
    \}$\\[0.5em]
$h$ is admissible because $h(s) \leq h^*(s) \ \forall s $ in $ \mathcal{S}$\\[0.5em]
